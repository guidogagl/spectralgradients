# Pretrained classifiers

The classifiers explained in the paper. `run.sh benchmark` loads them from this directory
(`SG_MODELS` overrides the location); `run.sh setup` checks them against `SHA256SUMS`.

| File | Model | Trained on | Training script |
|---|---|---|---|
| `synt-setup0.pt` | Conv1D (`synt/train.py::TimeConvNet`) | synthetic setup 0, 2000 samples/class, seed 0 | `synt/train.py` |
| `synt-setup1.pt` | Conv1D | synthetic setup 1 | `synt/train.py` |
| `synt-setup2.pt` | Conv1D | synthetic setup 2 | `synt/train.py` |
| `arrhythmia-cnn.pth` | Conv1D (`arrhythmia/train.py::SimpleConv1d`) | MIT-BIH Arrhythmia Database, DS1/DS2 split, 5 AAMI classes | `arrhythmia/train.py` |
| `audio-wavcnn.pt` | Conv1D (`audio/train.py::WaveCNNClassifier`) | Google Speech Commands v0.02, 35 words | `audio/train.py` |

The sleep-staging models (`chambon2018`, `tsinalis-2016`) are not stored here: they are the
pretrained PhysioEx models, downloaded at run time from the Hugging Face repository
`4rooms/physioex` by `physioex.models.load_from_pretrained`.

`run.sh train` retrains the three families into `models-retrained/` and never overwrites this
directory; a retrained classifier is statistically equivalent to the shipped one but not identical,
so the per-sample results of the paper are reproduced exactly only with the shipped weights
(`run.sh results` downloads those results directly).
